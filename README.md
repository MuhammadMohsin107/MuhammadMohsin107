## Engineering principles

| | |
| :-- | :-- |
| **Design for change** <br/> Systems that evolve without unnecessary rewrites. | **Clear boundaries** <br/> UI, business logic, data and infrastructure kept separate. |
| **Data is architecture** <br/> Schemas, validation, indexing and access patterns come first. | **Automate repetition** <br/> Recurring workflows become reliable automation. |
| **Prefer simplicity** <br/> Complexity only when the problem requires it. | **AI with purpose** <br/> AI where it creates real product value. |
